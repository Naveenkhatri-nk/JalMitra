## What was tried

- Streaming: measured above, but NOT used for display. Showing tokens before the checks finish would put unverified text on screen. Instead the chat shows the verified official answer at once and a 'checking the AI explanation' indicator until the checked text is ready (two-stage answer).
- Caching: verified/rejected outcomes cached in memory (key = question, language, mode, fact block, model, safety flags; errors never cached); query embeddings cached. Repeated questions take milliseconds.
- Retrieval: 226 chunks, k=4 - vector search itself is a few ms; the query embedding dominates.
- Not done: no bigger or new model, no lower-quality quantisation, no skipped checks.
