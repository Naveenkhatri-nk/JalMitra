# JalMitra: who did what (7 members)

JalMitra is a multilingual groundwater chatbot. A local AI model (Qwen3-4B Instruct, run by Ollama on the laptop) writes every reply. The reply is built only from official CGWB 2025 data and approved report passages, and checkers verify it before the user sees it.

**Team (Section DC, Department of CSE, JECRC University, 2025–2026) · Guide: Mr. Ajay**

The project is divided into 7 parts that follow the path of one question: **data → database & search → prompt → answer checking → languages → website → testing & results**. The presentation has 9 slides in the college format. Each member speaks for about 2 minutes (about 14 minutes in total, plus questions). The full speech for every member is in `JalMitra_Presentation_Speech.pdf`, and each member's own PDF explains their part with viva answers.
